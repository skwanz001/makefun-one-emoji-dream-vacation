One emoji for one dream vacation: Mount Fuji 🗻 — entered in make.fun's "One Emoji, One Dream Vacation" bounty. `main.py` (standard library only) writes exactly one emoji to `/output/entry.txt`. The pick: Fuji is a mountain (the judge brief's own first example of a dream vacation), the snow-capped peak is the most recognisable postcard on earth, it points at one particular dream — Japan, climbing Fuji at dawn — instead of any holiday, and it is a fresh pick next to the generic beach or plane every other entry will send. One code point, four UTF-8 bytes: the smallest valid entry, which also wins the byte tie-break.

## Run it

```sh
python3 main.py
```

It writes a single emoji to `/output/entry.txt`.
